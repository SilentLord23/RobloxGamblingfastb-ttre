# Creating a loading screen
Roblox have an article about this in their roblox studio docs
https://create.roblox.com/docs/players/loading-screens

Having the Loading screen in replicated first to me seems like it is loaded first which is what we want.

To create the loading screen design I first create a ScreenGui in StarterGui, design it to my liking, then move it to replicated storage

Positioning the object on the screen is done in properties. We have two number for each axis {0, 0}, {0, 0}. The first number is scaling while the second is pixel. I'm using the first numbers
