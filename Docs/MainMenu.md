# Main menu Creation

## Main menu scene

- Created the scene by making an empty box, adding grass and trees from the asset store in Roblox Studio. 
- Created a campfire using archimedes plugin to make a stone circle and wood colored parts. 
- Used a particle emmitter to add rain and F3x building tools to make a fire visual in the campfire.
- Modeled a bench using Built in solid modeling, union, intersection etc.
- Added tent and car models from the asset store.
- Added mainMenuCamera part to act as camera
